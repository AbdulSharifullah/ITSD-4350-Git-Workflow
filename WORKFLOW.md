# Git Workflow Documentation

## Workflow

This repository uses the Feature Branch Workflow. Changes are made on separate feature branches and merged into main using pull requests.

## Branch Naming

Feature branches use:

feature/<short-description>

Example: feature/add-workflow-documentation

## Commit Messages

This project uses Conventional Commits.

Examples:
- docs: update documentation
- feat: add new feature
- fix: correct an issue

## Merge Process

1. Create a feature branch from main.
2. Make and commit changes.
3. Open a pull request into main.
4. The pull request must be approved by another account.
5. Merge the pull request after approval.

The main branch is protected and requires one approval before merging.
